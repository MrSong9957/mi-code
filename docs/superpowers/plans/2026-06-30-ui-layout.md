# UILayout 终端UI渲染模块计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建统一的终端UI渲染模块，所有输出遵循统一格式（前缀、样式、缩进、换行）

**Architecture:** UILayout 是唯一出口，负责消息格式化、内容分区、布局计算。Renderer 降级为纯帧缓冲层。

**Tech Stack:** TypeScript, Vitest, Node.js

---

## 格式规范

| 类型 | 前缀 | 样式 | 缩进 | 示例 |
|------|------|------|------|------|
| `thinking` | `●` | 紫色圆点 | 0 | `● Thinking…` |
| `thinking_content` | 无 | 灰色 | 2 | `  用户问"你是谁？"…` |
| `thinking_end` | `  Thought for` | 灰色 | 2 | `  Thought for 17s, read 2 files` |
| `assistant` | `●` | 紫色圆点 | 0 | `● **我是一个AI助手**` |
| `tool_call` | `● {name}` | 紫色圆点+工具名 | 0 | `● Bash(cd ...)` |
| `tool_result` | `  ⎿` | 灰色 | 2 | `  ⎿  Done` |
| `tool_output` | `  ⎿` | 灰色 | 2 | `  ⎿  > npm test ...` |
| `permission` | `  ⎿` | 灰色 | 2 | `  ⎿  Allowed by auto mode classifier` |
| `system` | 无 | 默认 | 0 | `[Hook] Session started` |
| `error` | 无 | 红色 | 0 | `[Error] No API Key` |
| `input` | `❯` | 绿色粗体 | 0 | `❯ 你是谁？` |

```typescript
// src/ui/types.ts
// UI 渲染系统类型定义

/** 消息类型 */
export type UIMessageType =
  | 'thinking'          // thinking 开始（● Thinking…）
  | 'thinking_content'  // thinking 内容（灰色，2空格缩进）
  | 'thinking_end'      // thinking 结束（Thought for Ns）
  | 'assistant'         // AI 回复（● + Markdown）
  | 'tool_call'         // 工具调用（● name(args)）
  | 'tool_result'       // 工具结果（  ⎿  Done）
  | 'tool_output'       // 工具输出（  ⎿  > ...）
  | 'permission'        // 权限信息（  ⎿  Allowed...）
  | 'system'            // 系统消息
  | 'error'             // 错误信息
  | 'input';            // 用户输入（❯）

/** 消息元数据 */
export interface UIMessageMeta {
  toolName?: string;      // 工具名（用于 tool_call）
  toolArgs?: string;      // 工具参数（用于 tool_call）
  duration?: number;      // 耗时秒数（用于 thinking_end）
  filesRead?: number;     // 读取文件数（用于 thinking_end）
  linesAdded?: number;    // 添加行数（用于 tool_result）
  linesRemoved?: number;  // 删除行数（用于 tool_result）
  filePath?: string;      // 文件路径（用于 Update）
  output?: string;        // 输出内容（用于 tool_output）
  permission?: string;    // 权限信息（用于 permission）
}

/** 格式化后的消息行 */
export interface FormattedLine {
  content: string;    // 格式化后的内容（含前缀、缩进）
  style: UIMessageStyle;
  indent: number;     // 缩进空格数
}

/** 消息样式 */
export interface UIMessageStyle {
  fg?: string;
  bg?: string;
  bold?: boolean;
  dim?: boolean;
  italic?: boolean;
  underline?: boolean;
}

/** Writer 接口 */
export type Writer = (s: string) => void;

/** 终端尺寸 */
export interface TermSize {
  rows: number;
  cols: number;
}
```

### Task 2: 创建消息格式化器

**Files:**
- Create: `src/ui/message-formatter.ts`
- Create: `src/__tests__/ui/message-formatter.test.ts`

**实现：**

消息格式化器负责为每种消息类型生成符合格式规范的行。

**格式规则：**

| 类型 | 生成逻辑 |
|------|----------|
| `thinking` | `● Thinking…`（紫色圆点） |
| `thinking_content` | `  {content}`（2空格缩进，灰色） |
| `thinking_end` | `  Thought for {duration}s, read {filesRead} files (ctrl+o to expand)`（灰色） |
| `assistant` | `● {content}`（紫色圆点） |
| `tool_call` | `● {toolName}({toolArgs})`（紫色圆点+工具名） |
| `tool_result` | `  ⎿  Added {linesAdded} lines, removed {linesRemoved} lines`（灰色） |
| `tool_output` | `  ⎿  > {output}`（灰色） |
| `permission` | `  ⎿  {permission}`（灰色） |
| `system` | `{content}`（默认） |
| `error` | `{content}`（红色） |
| `input` | `❯ {content}`（绿色粗体） |

**测试用例：**

```typescript
describe('MessageFormatter', () => {
  describe('format', () => {
    it('should format thinking', () => {
      const lines = MessageFormatter.format('thinking', {});
      expect(lines[0].content).toBe('● Thinking…');
      expect(lines[0].style.fg).toBe('magenta');
    });

    it('should format thinking_content with indent', () => {
      const lines = MessageFormatter.format('thinking_content', {}, '用户问"你是谁？"');
      expect(lines[0].content).toBe('  用户问"你是谁？"');
      expect(lines[0].indent).toBe(2);
      expect(lines[0].style.dim).toBe(true);
    });

    it('should format thinking_end', () => {
      const lines = MessageFormatter.format('thinking_end', { duration: 17, filesRead: 2 });
      expect(lines[0].content).toBe('  Thought for 17s, read 2 files (ctrl+o to expand)');
      expect(lines[0].style.dim).toBe(true);
    });

    it('should format tool_call', () => {
      const lines = MessageFormatter.format('tool_call', { toolName: 'Bash', toolArgs: 'cd ...' });
      expect(lines[0].content).toBe('● Bash(cd ...)');
    });

    it('should format tool_output with indent', () => {
      const lines = MessageFormatter.format('tool_output', { output: '> npm test ...' });
      expect(lines[0].content).toBe('  ⎿  > npm test ...');
      expect(lines[0].indent).toBe(2);
    });

    it('should format input', () => {
      const lines = MessageFormatter.format('input', {}, '你是谁？');
      expect(lines[0].content).toBe('❯ 你是谁？');
      expect(lines[0].style.fg).toBe('green');
      expect(lines[0].style.bold).toBe(true);
    });
  });
});
```

**实现：**

内容分区管理器负责将消息分配到正确的区域（消息区/工具区/系统区）。

**区域定义：**

| 区域 | 包含的消息类型 | 特性 |
|------|---------------|------|
| 消息区 | thinking, thinking_content, thinking_end, assistant | 流式渲染 |
| 工具区 | tool_call, tool_result, tool_output, permission | 事件驱动 |
| 系统区 | system, error, input | 固化渲染 |

**测试用例：**

```typescript
describe('ContentRegion', () => {
  it('should route thinking to message region', () => {
    const region = new ContentRegion();
    region.addMessage('thinking', {});
    expect(region.getMessageRegion().length).toBe(1);
    expect(region.getToolRegion().length).toBe(0);
  });

  it('should route tool_call to tool region', () => {
    const region = new ContentRegion();
    region.addMessage('tool_call', { toolName: 'Bash' });
    expect(region.getToolRegion().length).toBe(1);
    expect(region.getMessageRegion().length).toBe(0);
  });

  it('should route system to system region', () => {
    const region = new ContentRegion();
    region.addMessage('system', {}, 'test');
    expect(region.getSystemRegion().length).toBe(1);
  });

  it('should clear regions', () => {
    const region = new ContentRegion();
    region.addMessage('thinking', {});
    region.addMessage('tool_call', { toolName: 'Bash' });
    region.clear();
    expect(region.getMessageRegion().length).toBe(0);
    expect(region.getToolRegion().length).toBe(0);
  });
```

## 阶段 2：UILayout 主模块

### Task 4: 创建 UILayout 主模块

**Files:**
- Create: `src/ui/ui-layout.ts`
- Create: `src/__tests__/ui/ui-layout.test.ts`

**实现：**

UILayout 是主入口，整合 MessageFormatter、ContentRegion、Renderer。

**核心 API：**

```typescript
class UILayout {
  constructor(options: UILayoutOptions);
  
  // 发送消息（自动格式化 + 路由）
  send(type: UIMessageType, content: string, meta?: UIMessageMeta): void;
  
  // 流式更新（thinking/assistant）
  appendStreaming(type: 'thinking' | 'assistant', content: string): void;
  
  // 固化流式内容
  finalizeStreaming(): void;
  
  // 更新输入框
  setInput(text: string, cursorPos: number): void;
  
  // 更新状态栏
  setStatus(status: StatusState): void;
  
  // 提交一帧
  commit(): void;
  
  // 清空所有内容
  clear(): void;
}
```

**测试用例：**

```typescript
describe('UILayout', () => {
  let layout: UILayout;
  let writer: ReturnType<typeof vi.fn>;

  beforeEach(() => {
    writer = vi.fn();
    layout = new UILayout({ rows: 24, cols: 80, writer });
  });

  describe('send', () => {
    it('should format and route thinking', () => {
      layout.send('thinking', {});
      layout.commit();
      expect(writer).toHaveBeenCalled();
    });

    it('should format and route tool_call', () => {
      layout.send('tool_call', '', { toolName: 'Bash', toolArgs: 'cd ...' });
      layout.commit();
      expect(writer).toHaveBeenCalled();
    });
  });

  describe('appendStreaming', () => {
    it('should accumulate thinking content', () => {
      layout.appendStreaming('thinking', '用户问"你是谁？"');
      layout.appendStreaming('thinking', '这是一个问题。');
      layout.commit();
      // 内容应该累积
    });
  });

  describe('finalizeStreaming', () => {
    it('should finalize thinking with duration', () => {
      layout.appendStreaming('thinking', '内容');
      layout.finalizeStreaming(17, 2);
      layout.commit();
      // 应该包含 "Thought for 17s, read 2 files"
    });
  });
});
```
