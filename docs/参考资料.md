根据 Claude Code 的技术栈，ZCode 需要以下官方文档作为参考：

## 核心依赖文档

### 1. Ink（React 终端 UI 框架）
```
https://github.com/vadimdemedes/ink
```
Claude Code 基于 Ink 构建，但做了大量魔改（自定义 reconciler、yoga-layout、alt-screen 支持）。

### 2. Yoga Layout（布局引擎）
```
https://yogalayout.dev/
https://github.com/facebook/yoga
```
终端 flexbox 布局的核心。Claude Code 用的是 TypeScript 移植版 `src/native-ts/yoga-layout/`。

### 3. ANSI 转义序列
```
https://invisible-island.net/xterm/ctlseqs/ctlseqs.html
```
终端控制的权威文档：光标移动、颜色、鼠标追踪、OSC 序列等。

### 4. VT100/VT220 参考
```
https://www.vt100.net/
```
传统终端协议基础。

## Claude Code 特有的魔改

Claude Code 在 Ink 基础上做了这些关键修改：

| 文件 | 作用 | 参考价值 |
|------|------|----------|
| `src/ink/selection.ts` | 文本选择状态机 | 实现选择功能的参考 |
| `src/ink/termio/osc.ts` | OSC 52 剪贴板 | 剪贴板操作参考 |
| `src/ink/hooks/use-declared-cursor.ts` | 光标声明机制 | 光标定位参考 |
| `src/ink/render-node-to-output.ts` | Yoga 树遍历渲染 | 渲染流程参考 |

## 建议给 ZCode 的参考资料

```markdown
# 终端渲染技术参考

## 必读文档
1. ANSI 转义序列: https://invisible-island.net/xterm/ctlseqs/ctlseqs.html
2. Yoga Layout: https://yogalayout.dev/
3. Ink README: https://github.com/vadimdemedes/ink

## 关键协议
- OSC 52: 剪贴板写入
- SGR 鼠标: \033[?1006h 开启
- Alt Screen: \033[?1049h 进入
```
